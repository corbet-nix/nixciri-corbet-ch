nixciri

Ciri's config grammar, generated from neutral desktop intent.

A Home Manager module that writes ~/.config/ciri/config.kdl, translates shared display and session contracts, and leaves personal bindings, colors, rules, and desktop components to the consumer.

See the boundary View source

One compositor, three owners

ciri

The runtime product: compositor source, renderer and protocol fixes, command-line interface, and runtime identity.

nixciri

The public integration: KDL serialization and translation from neutral display, startup, session, and device contracts.

ciri.nix

Private values: selected layouts, key bindings, colors, gaps, application rules, and host overrides.

What the module translates

Displays

nixdisplay.layouts and nixdisplay.monitors become typed output blocks, including identity aliases, transforms, positions, scales, modes, and modelines.

Session devices

Neutral session device names are resolved through stable GPU paths before Ciri's render-device and denylist directives are written.

Startup

Generic nixdesktop.startup command strings become shell-aware startup directives. The module invents no components.

Public surface

Import

imports = [ inputs.nixciri.homeManagerModules.ciri ];

Configure

programs.ciri = {
  enable = true;
  layout = "docked";
  session = "primary";
  package = ciriPackage;
};

Clean API

The module is exported as homeManagerModules.ciri, uses programs.ciri.*, and writes only the Ciri config path. No compatibility aliases are provided.
